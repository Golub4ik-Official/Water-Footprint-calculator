# 🌊 Калькулятор водного следа | Water Footprint Calculator

Интерактивный веб-сайт для расчёта индивидуального водного следа человека. Проект помогает пользователям осознать своё влияние на водные ресурсы планеты через бытовое потребление, питание и покупку товаров.

## 📋 О проекте

Водный след — это объём пресной воды, используемой для производства товаров и услуг, потребляемых человеком. Этот проект позволяет рассчитать свой личный водный след и сравнить его со средними мировыми показателями.

### Основные функции

- 🧮 **Калькулятор водного следа** — расчёт на основе бытового потребления, питания и покупок
- 📊 **Интерактивные таблицы** — данные о водном следе различных продуктов питания
- 💡 **Рекомендации** — советы по снижению водного следа
- 📱 **Адаптивный дизайн** — корректная работа на мобильных и десктопных устройствах
- ✨ **Современный UI** — плавные анимации и интуитивный интерфейс

## 🚀 Технологии

## 📦 Установка и запуск

### Требования

- Любой современный веб-браузер (Chrome, Firefox, Safari, Edge)
- Локальный веб-сервер (опционально, для корректной работы с некоторыми функциями)

### Запуск проекта

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd water-footprint-calculator
   ```

2. **Запуск через локальный сервер**
   
   **Вариант 1: Python**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   ```

   **Вариант 2: Node.js (http-server)**
   ```bash
   npx http-server -p 8000
   ```

   **Вариант 3: VS Code Live Server**
   - Установите расширение "Live Server" в VS Code
   - Откройте `index.html`
   - Нажмите правой кнопкой мыши → "Open with Live Server"

3. **Открытие в браузере**
   
   Перейдите по адресу: `http://localhost:8000`

   Также можно просто открыть файл `index.html` в браузере двойным кликом.

## 🎯 Функционал калькулятора

### Категории расчёта

1. **Бытовое потребление**
   - Время в душе
   - Принятие ванн
   - Мытьё посуды
   - Стирка
   - Смыв туалета

2. **Питание**
   - Мясо и рыба
   - Молочные продукты и яйца
   - Злаки и крупы
   - Овощи и фрукты
   - Напитки
   - Масла и жиры
   - Бобовые и орехи
   - Сахар и сладости

3. **Товары**
   - Одежда
   - Электроника
   - Книги
   - Средства гигиены

### Результаты расчёта

Калькулятор предоставляет:
- Детальный разбор по категориям
- Общий водный след в литрах в день
- Сравнение со средними показателями
- Персонализированные рекомендации

## 📊 Источники данных

Данные о водном следе продуктов основаны на научных исследованиях:

- **Mekonnen, M.M. & Hoekstra, A.Y. (2011).** "The green, blue and grey water footprint of crops and derived crop products." *Hydrology and Earth System Sciences*, 15, 1577–1600.
- **Mekonnen, M.M. & Hoekstra, A.Y. (2012).** "A Global Assessment of the Water Footprint of Farm Animal Products." *Ecosystems*, 15: 401–415.

Значения представляют средние глобальные показатели за период 1996-2005 гг.

## 🔧 Разработка

### Добавление новых продуктов

Для добавления нового продукта в калькулятор:

1. Добавьте input в `index.html` в соответствующую категорию
2. Обновите логику расчёта в `script.js` в функции `calculateWaterFootprint()`
3. Добавьте коэффициент водного следа (литров/кг или литров/литр)

### Стилизация

Все стили находятся в `styles.css` и организованы по секциям:
- Общие стили
- Навигация
- Главная секция
- Калькулятор
- Таблицы
- Информационные секции
- Адаптивность (медиа-запросы)
